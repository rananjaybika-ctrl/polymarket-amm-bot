# Plan 04-02: Strategy Validation

## Goal
Create a dry run simulation that runs the complete trading loop through multiple market cycles to validate strategy profitability before going live.

## Components

### 1. DryRunSimulator
Orchestrates the full trading loop in simulation mode.

**Features:**
- Runs through multiple markets
- Uses PaperTradingEngine for execution
- Tracks performance metrics
- Generates detailed reports

### 2. SimulationReport
Comprehensive results after dry run.

- Per-market breakdown
- Win/loss analysis
- Risk metrics
- Recommendations

## Implementation

### File: `src/services/dry_run.py`

```python
class DryRunSimulator:
    async def run(
        duration_minutes: int = 60,
        target_markets: int = 4,
    ) -> SimulationReport
```

### Integration
- Uses MarketRotator for market selection
- Uses PairAnalyzer for opportunity detection
- Uses PaperTradingEngine for execution
- Real market data via API/WebSocket

## Dry Run Flow

```
1. Initialize services
2. Start MarketRotator (continuous mode)
3. For each market cycle:
   a. Find profitable opportunity
   b. Validate with BalanceManager
   c. Execute paper trade
   d. Track results
4. When market expires, rotate to next
5. Resolve completed markets
6. Generate report
```

## Test Scenarios

1. **Profitable conditions**: Pair cost < $1.00
2. **No opportunities**: Pair cost >= $1.00
3. **Partial fills**: One side doesn't fill
4. **Market rotation**: Transition between markets
5. **Balance limits**: Insufficient funds

## Success Criteria
- [ ] Full trading loop runs end-to-end
- [ ] Multiple market cycles simulated
- [ ] Performance report generated
- [ ] Edge cases handled gracefully
