# Plan: Polywalltrack - Multi-Market Wallet Analyzer

## Objective

Create `scripts/polywalltrack.py` - a CLI tool that analyzes a Polymarket wallet's performance across multiple markets, outputting a concise quantitative report.

## Context

Reference files:
- @scripts/chart_generator.py - Existing single-market analyzer (API patterns, data structures)
- @.claude/TRADE_ANALYSIS_PLAYBOOK.md - Report structure inspiration

Target wallet for testing: `0x6031b6eed1c97e853c6e0f03ad3ce3529351f96d` (gabagool22)

## Tasks

### Task 1: Create polywalltrack.py core structure
**Type**: code
**Files**: `scripts/polywalltrack.py`
**Action**:
1. Create CLI interface:
   - Required: `--wallet` or `-w` (wallet address)
   - Required: `--markets` or `-m` (comma-separated market slugs OR market search queries)
   - Optional: `--output` or `-o` (output file, default: stdout)
2. Reuse from chart_generator.py:
   - `search_market()` function for market lookup
   - `fetch_trades()` function for trade fetching
   - Trade parsing logic (side, outcome, price, shares, cost)
3. Add multi-market iteration logic

**Verify**: `python scripts/polywalltrack.py --help` shows usage

### Task 2: Implement per-market analysis
**Type**: code
**Files**: `scripts/polywalltrack.py`
**Action**:
1. For each market, calculate:
   - Trade count
   - YES/NO shares bought/sold
   - Net position (remaining shares)
   - Total cost (net exposure)
   - Winner (infer from final trade prices or prompt)
   - PNL = payout - cost
2. Store results in list of market dicts

**Verify**: Single market analysis matches chart_generator output
