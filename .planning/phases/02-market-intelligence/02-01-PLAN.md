# Plan 02-01: Market Data Fetching

## Goal
Fetch and filter Polymarket markets to find active BTC 15-minute Up/Down markets, providing the foundation for trading decisions.

## Context
The bot trades BTC 15-minute binary markets where users bet if BTC goes Up or Down within a 15-minute window. Each market has two tokens (Up/Down) that form a pair. We need to reliably find these markets from Polymarket's API.

## Dependencies
- Phase 1 complete (Config, PolymarketClient)
- `src/api/polymarket_client.py` - has `get_markets()` method

## Implementation Steps

### Step 1: Explore Polymarket API Response Structure
**Files**: None (exploration)
**Actions**:
- Create test script to fetch raw market data
- Document the response structure (fields, nested objects)
- Identify which fields distinguish BTC 15-min markets from others
- Find the token IDs for Up/Down outcomes

### Step 2: Create Market Models
**Files**: `src/models/__init__.py`, `src/models/market.py`
**Actions**:
- Create `src/models/` directory
- Define `BTCMarket` dataclass with fields:
  - `condition_id`: Market identifier
  - `question`: Market question text (e.g., "Will BTC go up in the next 15 minutes?")
  - `up_token_id`: Token ID for Up outcome
  - `down_token_id`: Token ID for Down outcome
  - `end_time`: When the market resolves (datetime)
  - `active`: Whether market accepts orders
- Add helper methods: `time_remaining()`, `is_expired()`

### Step 3: Create Market Finder Service
**Files**: `src/services/__init__.py`, `src/services/market_finder.py`
**Actions**:
- Create `src/services/` directory
- Implement `MarketFinder` class:
  - `find_btc_15min_markets()` - Filter all markets to BTC 15-min
  - `get_active_market()` - Get the currently active market
  - `get_next_market()` - Get the upcoming market (for rotation)
- Filter logic: Match by question text pattern or market tags
- Sort by end_time to identify current vs upcoming

### Step 4: Create Test Script
**Files**: `scripts/test_market_finder.py`
**Actions**:
- Script to demonstrate market finding works
- Print current active BTC 15-min market details
- Show Up/Down token IDs
- Display time remaining until resolution

### Step 5: Add Error Handling
**Files**: `src/services/market_finder.py`
**Actions**:
- Handle case when no BTC markets found
- Handle API pagination (markets may span multiple pages)
- Add retry logic for transient failures
- Log warnings for markets with missing data
