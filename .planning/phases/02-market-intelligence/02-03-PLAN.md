# Plan 02-03: Market Rotation

## Goal
Implement automatic market rotation to trade consecutive 15-minute BTC Up/Down markets within a 60-minute trading window (max 4 markets).

## Context
The bot should seamlessly transition between 15-minute markets:
1. Start trading on first active market
2. When market ends/expires, automatically switch to next market
3. Enforce 60-minute maximum window (4 consecutive markets)
4. Handle gaps between markets gracefully

## Dependencies
- Plan 02-01: MarketFinder service
- Plan 02-02: PairAnalyzer service

## Implementation Steps

### Step 1: Create MarketRotator Service
**Files**: `src/services/market_rotator.py`
**Actions**:
- Define `MarketRotator` class:
  - `current_market`: Currently active BTCMarket
  - `markets_traded`: Count of markets in session
  - `session_start`: When trading session began
  - `max_markets`: Maximum markets per session (default 4)
  - `max_duration`: Maximum session duration (default 60 min)
- Methods:
  - `start_session()`: Initialize rotation with first market
  - `get_current_market()`: Return active market or None
  - `should_rotate()`: Check if rotation needed
  - `rotate()`: Advance to next market
  - `is_session_complete()`: Check if session limits reached

### Step 2: Add Rotation Logic
**Files**: `src/services/market_rotator.py`
**Actions**:
- Implement rotation triggers:
  - Current market expired
  - Current market no longer accepting orders
  - Manual rotation request
- Handle edge cases:
  - No next market available
  - Gap between markets (wait vs skip)
  - Market becomes unavailable mid-trade

### Step 3: Add Session Management
**Files**: `src/services/market_rotator.py`
**Actions**:
- Track session statistics:
  - Markets traded
  - Total time elapsed
  - Profits per market
- Implement session limits:
  - Max 4 markets per session
  - Max 60 minutes per session
- Clean session end handling

### Step 4: Create Test Script
**Files**: `scripts/test_market_rotation.py`
**Actions**:
- Demonstrate market rotation logic
- Show session timeline
- Display rotation triggers
- Simulate full 60-min session

### Step 5: Integrate with PairAnalyzer
**Files**: `src/services/market_rotator.py`
**Actions**:
- Method to get analyzer for current market
- Automatic re-analysis on rotation
- Opportunity tracking across rotation
