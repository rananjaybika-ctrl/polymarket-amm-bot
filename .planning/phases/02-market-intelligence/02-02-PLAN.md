# Plan 02-02: Orderbook Analysis

## Goal
Analyze orderbooks for BTC 15-minute markets to detect pair cost < $1.00 opportunities and calculate spreads for trading decisions.

## Context
With BTCMarket providing Up and Down token IDs, we can now fetch orderbooks for both sides of a market. The key insight is that if `Up_ask + Down_ask < $1.00`, we can buy both sides and guarantee profit on resolution (one pays $1, the other $0).

## Dependencies
- Plan 02-01 complete (BTCMarket model, MarketFinder service)
- `src/api/polymarket_client.py` - has `get_orderbook()` and `get_orderbooks()` methods

## Implementation Steps

### Step 1: Create Orderbook Model
**Files**: `src/models/orderbook.py`
**Actions**:
- Define `Order` dataclass (price, size, side)
- Define `Orderbook` dataclass:
  - `token_id`: Token identifier
  - `bids`: List of bid orders (sorted by price desc)
  - `asks`: List of ask orders (sorted by price asc)
  - `best_bid`: Highest bid price
  - `best_ask`: Lowest ask price
  - `spread`: Ask - Bid
  - `mid_price`: (Ask + Bid) / 2
- Factory method: `from_clob_response()` to parse API data

### Step 2: Create Pair Analyzer
**Files**: `src/services/pair_analyzer.py`
**Actions**:
- Define `PairOpportunity` dataclass:
  - `market`: BTCMarket reference
  - `up_orderbook`: Orderbook for Up token
  - `down_orderbook`: Orderbook for Down token
  - `pair_cost`: Up_ask + Down_ask
  - `potential_profit`: $1.00 - pair_cost
  - `executable_size`: Min of Up ask size and Down ask size
- Implement `PairAnalyzer` class:
  - `analyze_market(market) -> PairOpportunity`
  - `is_profitable(opportunity, min_profit) -> bool`
  - `get_best_opportunity(markets) -> PairOpportunity`

### Step 3: Integrate with PolymarketClient
**Files**: `src/api/polymarket_client.py` (update)
**Actions**:
- Add method to fetch orderbooks for a BTCMarket (both tokens at once)
- Return structured Orderbook objects instead of raw dicts

### Step 4: Create Test Script
**Files**: `scripts/test_orderbook_analysis.py`
**Actions**:
- Fetch active BTC 15-min market
- Get orderbooks for Up and Down tokens
- Calculate and display pair cost
- Show if opportunity is profitable
- Display depth at various price levels

### Step 5: Add Pair Cost Monitoring
**Files**: `src/services/pair_analyzer.py` (update)
**Actions**:
- Method to continuously monitor pair cost
- Callback when pair_cost drops below threshold
- Historical pair cost tracking for analysis
