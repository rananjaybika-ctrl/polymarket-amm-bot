# Plan 03-02: Position Tracking

## Objective
Track positions, calculate P&L, and maintain inventory state for the trading bot.

## Background

### API Methods Available
- `get_balance_allowance(AssetType.CONDITIONAL, token_id)`: Get position balance
- `get_trades(TradeParams)`: Get trade history
- `get_position_balance(token_id)`: Wrapper in PolymarketClient

### Position Types
For each market, we hold:
- **Up Position**: Number of Up tokens
- **Down Position**: Number of Down tokens

For pair trading, we should have equal Up and Down positions (balanced pair).

## Implementation

### Step 1: Position Model
Create `src/models/position.py`:

**Position dataclass:**
- market: BTCMarket
- up_balance: float (from chain)
- down_balance: float (from chain)
- up_avg_price: float
- down_avg_price: float
- total_cost: float
- created_at: datetime

**Properties:**
- `pair_count`: min(up_balance, down_balance) - matched pairs
- `unmatched_up`: up_balance - pair_count
- `unmatched_down`: down_balance - pair_count
- `is_balanced`: up_balance == down_balance
- `unrealized_pnl`: Value if sold now vs cost

### Step 2: PositionTracker Service
Create `src/services/position_tracker.py`:

**Core Methods:**
- `sync_position(market)`: Fetch balances from chain
- `add_fill(market, side, price, size)`: Record a fill
- `get_position(market)`: Get current position
- `get_all_positions()`: List all positions

**P&L Calculation:**
- `calculate_unrealized_pnl(position)`: Based on current prices
- `calculate_realized_pnl(position)`: From completed trades
- `get_total_pnl()`: Sum across all positions

**Inventory Management:**
- `get_total_exposure()`: Sum of position values
- `get_imbalance()`: Unmatched positions
- `needs_rebalance()`: Check if action needed

### Step 3: Integration with OrderExecutor
Update position on every fill:
- OrderExecutor calls `tracker.add_fill()` after successful execution
- Position automatically updated with new balances

### Step 4: Test Script
Create `scripts/test_position_tracking.py`:
- Sync positions from chain
- Display current holdings
- Calculate P&L for positions
- Show imbalance warnings
