# Plan 03-05: WebSocket Integration

## Objective
Implement real-time orderbook streaming via Polymarket WebSocket for instant price updates and fill notifications.

## Background

### Polymarket WebSocket Endpoints
- **CLOB Market**: `wss://ws-subscriptions-clob.polymarket.com/ws/market`
- **CLOB User**: `wss://ws-subscriptions-clob.polymarket.com/ws/user`

### Event Types
- `book`: Order book updates (bids/asks)
- `price_change`: Best bid/ask updates
- `last_trade_price`: Trade execution notifications

### Subscription Message Format
```json
{
  "type": "market",
  "assets_ids": ["token_id_1", "token_id_2"]
}
```

## Implementation

### Step 1: WebSocket Client
Create `src/api/websocket_client.py`:

**WebSocketClient class:**
- `connect()`: Establish connection
- `disconnect()`: Clean shutdown
- `subscribe(token_ids)`: Subscribe to markets
- `unsubscribe(token_ids)`: Unsubscribe
- `on_book_update(callback)`: Register book handler
- `on_price_change(callback)`: Register price handler
- `on_trade(callback)`: Register trade handler

**Auto-reconnect:**
- Exponential backoff on disconnect
- Re-subscribe to previous markets
- Connection health monitoring

### Step 2: Message Models
Create message dataclasses:

**BookUpdate:**
- token_id: str
- bids: List[Order]
- asks: List[Order]
- timestamp: datetime

**PriceChange:**
- token_id: str
- best_bid: float
- best_ask: float
- timestamp: datetime

### Step 3: Integration with PairAnalyzer
- Stream prices for active markets
- Update PairOpportunity on price change
- Trigger alerts when pair_cost < $1.00

### Step 4: Test Script
Create `scripts/test_websocket.py`:
- Connect to WebSocket
- Subscribe to market
- Display real-time updates
- Test reconnection
