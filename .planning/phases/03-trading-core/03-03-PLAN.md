# Plan 03-03: Balance Management

## Objective
Implement balance management with imbalance detection, recovery logic, and risk controls.

## Background

### What Can Go Wrong
1. **Partial fills**: One side of pair fills, other doesn't
2. **Network issues**: Order submitted but response lost
3. **Price movement**: Opportunity disappears during execution
4. **Insufficient funds**: Not enough USDC for pair

### Current State
- PositionTracker detects imbalances via `get_imbalanced_positions()`
- `needs_rebalance(threshold)` checks if action needed
- No automated recovery yet

## Implementation

### Step 1: BalanceManager Service
Create `src/services/balance_manager.py`:

**Core Methods:**
- `check_sufficient_funds(cost)`: Verify USDC balance before trade
- `get_max_pair_size(opportunity)`: Max pairs given balance + opportunity
- `validate_pair_execution(result)`: Check if both sides filled

**Recovery Logic:**
- `recover_imbalance(position)`: Strategy to fix imbalanced position
- `sell_excess(position, side)`: Sell unmatched tokens
- `buy_matching(position, side)`: Buy matching tokens

**Risk Controls:**
- `get_available_capital()`: USDC available for new trades
- `check_position_limits(market)`: Max position per market
- `check_daily_loss_limit()`: Stop trading if loss exceeded

### Step 2: Recovery Strategies

**For excess Up tokens (unmatched_up > 0):**
1. Try to buy Down at good price to complete pair
2. If no good price, sell Up at market to exit

**For excess Down tokens (unmatched_down > 0):**
1. Try to buy Up at good price to complete pair
2. If no good price, sell Down at market to exit

**Decision factors:**
- Current bid price for selling
- Current ask price for buying match
- Whether completing pair is still profitable

### Step 3: Pre-Trade Validation
Before executing any trade:
1. Check USDC balance sufficient
2. Check position limits not exceeded
3. Verify opportunity still valid
4. Calculate maximum safe size

### Step 4: Test Script
Create `scripts/test_balance_management.py`:
- Test fund sufficiency checks
- Test max pair size calculation
- Simulate imbalance recovery decisions
- Test risk limit enforcement
