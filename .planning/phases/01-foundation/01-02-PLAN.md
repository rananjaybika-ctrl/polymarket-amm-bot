       - API host: https://clob.polymarket.com
    3. Create polymarket_client.py:
       - PolymarketClient class wrapping ClobClient
       - __init__ takes config, initializes client with credentials
       - get_balance() - fetch USDC balance
       - get_markets() - list available markets
       - get_orderbook(token_id) - get orderbook for specific market
       - Async methods using aiohttp where beneficial
       - Clear error handling with descriptive messages
       - Add docstrings explaining each method for beginner clarity
    4. Handle API credentials:
       - Load WALLET_PRIVATE_KEY from config
       - Use ApiCreds from py-clob-client for signing
