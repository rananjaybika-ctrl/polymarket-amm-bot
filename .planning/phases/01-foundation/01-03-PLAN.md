<task type="auto">
  <name>Task 2: Create network switcher with auto-failover</name>
  <files>src/utils/network_monitor.py (extend), scripts/test_network.py</files>
  <action>
    1. Add to NetworkMonitor class:
       - switch_network(ssid, password=None) - switch to specific network:
         * macOS: networksetup -setairportnetwork en0 "SSID" "password"
         * Wait for connection (up to 10 seconds)
         * Return success/failure
       - failover() - automatic failover logic:
         * If internet down on current network:
           1. Try BACKUP_WIFI_1
           2. If fail, try BACKUP_WIFI_2
           3. If all fail, log error and retry after interval
         * Set is_on_backup = True when on backup
       - check_and_restore_primary() - poll for primary:
         * Only runs when is_on_backup = True
         * Check if PRIMARY_WIFI is available and has internet
         * If yes, switch back and set is_on_backup = False
         * Log: "Restored to primary network"
       - start_monitoring(callback=None) - main monitoring loop:
         * Run as async task
         * Every POLL_INTERVAL (15s):
           - check_internet()
           - If down: failover()
           - If on backup: check_and_restore_primary()
         * Call callback on network change (for notifications)
    2. Create scripts/test_network.py:
       - Initialize NetworkMonitor with config
       - Display current network
       - Test internet connectivity
       - Show available networks
       - Simulate failover (optional - manual trigger)
    3. Store WiFi passwords securely:
       - Add BACKUP_WIFI_1_PASSWORD, BACKUP_WIFI_2_PASSWORD to config
       - Passwords in .env (gitignored)
  </action>
  <verify>
    - python scripts/test_network.py shows current network and internet status
    - NetworkMonitor can detect when internet is down
    - switch_network() changes WiFi (test manually with known network)
  </verify>
  <done>Network failover works: detects outage, switches to backup, polls to restore primary</done>
