<task type="checkpoint:human-action" gate="blocking">
  <action-needed>Create Discord webhooks for 3 channels</action-needed>
  <instructions>
    In your Discord server:

    1. Create 3 text channels (if not already created):
       - #pnl-summary
       - #losses
       - #outages

    2. For EACH channel, create a webhook:
       - Right-click channel → Edit Channel → Integrations → Webhooks
       - Click "New Webhook"
       - Name it (e.g., "AMM Bot PNL")
       - Click "Copy Webhook URL"
       - Save each URL

    3. Get your Discord User ID (for @mentions):
       - Enable Developer Mode: User Settings → Advanced → Developer Mode
       - Right-click your username → Copy User ID

    4. Add to your .env file:
       DISCORD_WEBHOOK_PNL=https://discord.com/api/webhooks/...
       DISCORD_WEBHOOK_LOSSES=https://discord.com/api/webhooks/...
       DISCORD_WEBHOOK_OUTAGES=https://discord.com/api/webhooks/...
       DISCORD_USER_ID=123456789012345678
  </instructions>
  <resume-signal>Type "webhooks ready" when all 3 webhook URLs and user ID are in .env</resume-signal>
</task>

<task type="auto">
  <name>Task 2: Create Discord notification module</name>
  <files>src/utils/discord_notifier.py, scripts/test_discord.py</files>
  <action>
    1. Create DiscordNotifier class:
       - __init__ takes config (webhook URLs, user ID)
       - Uses discord-webhook library (already in requirements)
       - Three notification methods:

         a) send_pnl(message, details=None):
            - Sends to #pnl-summary webhook
            - Green embed for profits, includes trade details
            - NO @mention (routine notifications)
            - Format: "Trade Complete: +$X.XX locked profit"

         b) send_loss(message, details=None):
            - Sends to #losses webhook
            - Red embed for losses
            - INCLUDES @mention: f"<@{user_id}>"
            - Format: "LOSS ALERT: -$X.XX on [market]"

         c) send_outage(message, outage_type="network"):
            - Sends to #outages webhook
            - Orange/yellow embed for warnings
            - INCLUDES @mention: f"<@{user_id}>"
            - Types: "network", "api", "website"
            - Format: "OUTAGE: [type] - [details]"

       - Helper method for embeds:
         * create_embed(title, description, color, fields=[])
         * Colors: green=#00ff00, red=#ff0000, orange=#ff9900

       - Error handling:
         * Catch webhook errors gracefully
         * Log failed notifications locally
         * Don't crash bot if Discord is down

    2. Create scripts/test_discord.py:
       - Send test message to each channel
       - Test @mention formatting
       - Verify embeds display correctly
  </action>
  <verify>

  </verify>
  <done>DiscordNotifier sends to correct channels, @mentions work, embeds display properly</done>
